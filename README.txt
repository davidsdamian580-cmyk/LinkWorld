LINKWORLD PRO
===============
This is a front-end affiliate/deal discovery website.

IMPORTANT:
1. Replace every example.com URL in script.js with an affiliate URL supplied by an affiliate program that has approved you.
2. Do not put bank account numbers, passwords, card details, API secrets, or other sensitive credentials into this website.
3. Bank payout setup belongs in the affiliate network's secure dashboard. The network pays cleared commissions according to its terms.
4. Earnings are not guaranteed and usually require a qualifying purchase, subscription, or signup rather than a simple click.
5. Keep an affiliate disclosure and follow each network's advertising rules and applicable tax/privacy requirements.

FILES:
index.html  - website
style.css   - design
script.js   - catalogue, search and filtering

To edit an offer:
Open script.js and change title, category, country, description and URL.


EFT PAYOUT UI
=============
The updated site includes a South Africa EFT payout preference form and a bank selector.

This form is deliberately front-end only. It does NOT send, store, or transmit bank account details.
For real affiliate payouts, configure EFT inside the affiliate network's secure payout settings.
The listed banks are common South African banking options; the exact banks/payment methods available depend on the affiliate network.
